# ПРОМЕТРИКА · демонстрационный стенд

Статическая демонстрация платформы мониторинга производства ПРОМЕТРИКА: OEE, простои,
потери и мощность производственных линий. Всё работает в браузере, сервер не нужен.
Данные обезличены и генерируются симулятором.

Стенд: https://snganzhela-design.github.io/prometrika-demo/ — вход по коду доступа,
код выдаёт представитель ПРОМЕТРИКИ.

Содержимое папки `docs` собирается из основного проекта и публикуется GitHub Pages как есть.
