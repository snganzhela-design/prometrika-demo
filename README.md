# ПРОМЕТРИКА · демонстрационный стенд

Живая веб-демка платформы мониторинга производства ПРОМЕТРИКА (OEE, простои,
история, табло). Данные полностью обезличены и генерируются симулятором;
выпуск продукции поступает из встроенного демо-стенда «Честного знака».

**Живая демка: https://snganzhela-design.github.io/prometrika-demo/** —
вход по коду доступа (сообщается клиентам лично). Движок демо работает
прямо в браузере посетителя, сервер не требуется.

## Состав

- `docs/` — статическая демка для GitHub Pages: страница входа + приложение
  + браузерный движок (`engine.js`); публикуется автоматически при push в main
- `server.js` + `web/` + `data/` — тот же стенд как сервер (вариант для Render,
  см. `render.yaml`; код доступа — переменная окружения `PROMETRIKA_DEMO_CODE`)

Сборка обоих вариантов — из основного проекта:
`tools/make-pages-demo.mjs` (статика) и `tools/make-web-demo.ps1` (сервер).
Данные и интерфейс обезличены, публикация проходит автоматический гейт.

## Локальный запуск серверного варианта

```
PROMETRIKA_NO_WINDOW=1 PROMETRIKA_DEMO_CODE=тест node server.js
```
