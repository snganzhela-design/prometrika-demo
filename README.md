# ПРОМЕТРИКА · демонстрационный стенд

Живая веб-демка платформы мониторинга производства ПРОМЕТРИКА (OEE, простои,
история, табло). Данные полностью обезличены и генерируются симулятором;
выпуск продукции поступает из встроенного демо-стенда «Честного знака».

Доступ к стенду — по коду (переменная окружения `PROMETRIKA_DEMO_CODE`,
задаётся в настройках сервиса на Render; там же её можно сменить в любой момент).

## Состав

- `server.js` — сервер (сборка, без исходников)
- `web/` — веб-интерфейс (сборка)
- `data/ivams.json` — обезличенные демонстрационные данные
- `render.yaml` — схема развёртывания на Render

## Развёртывание

1. [dashboard.render.com](https://dashboard.render.com) → **New → Blueprint** → выбрать этот репозиторий.
2. Render прочитает `render.yaml` и создаст сервис `prometrika-demo` (тариф Free).
3. Адрес демки появится в карточке сервиса: `https://prometrika-demo-XXXX.onrender.com`.

Каждый push в ветку `main` автоматически перевыкладывает демку.

## Локальный запуск

```
PROMETRIKA_NO_WINDOW=1 PROMETRIKA_DEMO_CODE=тест node server.js
```
